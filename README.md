# 空压站多机协同智能调度 Agent

面向制造企业空压站运维人员、能源管理人员、设备工程师和管理者的工业 Web 智能应用。
具备「感知 → 推理 → 决策 → 人工确认 → 执行 → 验证 → 学习」完整闭环的多机协同调度 Agent（演示环境）。

- 站点：空压站 · 1 号空压站，2 台阿特拉斯 ZH1250-6 离心式空压机（4#、5#）
- 默认免登录，顶部可切换四种角色（值班员 / 能源负责人 / 设备工程师 / 系统管理员）体验权限差异
- **运行数据接入真实数据包**（2026-03-12 ~ 2026-09-12，分钟级），聚合后供页面消费
- 调度方案、告警、工单、策略等**业务流程为演示逻辑**，页面各处保留「演示环境」标识

## 技术栈

React 18 + TypeScript + Vite 5 + Ant Design 5 + ECharts 5 + Zustand（含 localStorage 持久化）+ React Router 6

## 真实数据接入

站点运行数据来自数据包（9 个文件：3 个 CSV、4 个 XLSX、2 个 JSON），通过预处理脚本聚合为前端数据集。

```bash
# 由数据包重新生成聚合数据集（输出 src/data/generated/realDataset.json）
python3 scripts/build_real_dataset.py
```

- 数据层：`src/data/realDataset.ts`（类型封装）、`src/data/stationConfig.ts`（配置单一来源）、`src/data/stationTime.ts`（时间轴采样）
- 数据外置：聚合产物同时输出到 `public/data/realDataset.json`，`main.tsx` 启动时 fetch 注入，**替换数据包无需重新构建**
- 设备档案：2 台机组，参数取自 `设备档案.json`；健康分与喘振风险由 `src/utils/health.ts` 基于真实测点计算
- 时序聚合：日级 185 条、小时级（近 30 天）721 条、实时（末尾 6h）361 条、负荷预测 16 点、全周期小时级序列（供历史回放）
- 数据质量：脚本自动识别 B 相电流恒零、加卸载/预警缺失、保养剩余时间溢出等 7 项问题
- 字段口径与集成缺口详见 `.cosmocode/docs/real-data-integration.md`

## 核心业务故事线（验收演示路径）

1. **发现风险**：工作台/运行管理可见 5# 二级振动偏高（约 9.1 mm/s）、4# 温升偏高（排气峰值 115℃）及 B 相电流缺失告警。
2. **生成方案**：智能调度页点「一键生成调度方案」，约 4 秒完成（模拟 ≤60 秒目标），产出三套候选方案与解释依据。
3. **人工审批**：比较三套方案的节能收益/压力风险/设备风险，可编辑参数后以「值班员」批准（或驳回并填写原因）。
4. **模拟下发**：执行中心确认影响范围后下发，逐设备返回回执；AC-04 网关约 30% 概率超时 → 方案标记「状态未知」→ 重新下发或人工处置。
5. **效果复盘**：执行完成展示实际节电、压力合格率、加载率偏离与收益可信度说明。
6. **预测运维**：设备健康页查看 5# 二级振动诊断（提前 72h，均值约 9.1 mm/s）与 4# 温升诊断（排气峰值 115℃），一键建单。
7. **工单闭环**：以「设备工程师」指派 → 开工 → 提交复测数据 → 验收关闭（无复测数据时禁止关闭）。
8. **策略学习**：以「管理员」查看策略候选版本（源自驳回原因与执行效果）、历史回放结果，发布或回滚。
9. **Agent 问答**：询问"为什么 5# 二级振动偏高？""当前有哪些设备风险？""帮我生成调度方案"等，回答含结论/依据/风险/下一步；控制意图只会创建待审批方案。

## 真实站点与数据

- **设备**：4#、5# 空压机，均为阿特拉斯 ZH1250-6 离心机（1250 kW / 268.9 m³/min / 额定排气压力 0.66 MPa）
- **真实异常**：① 5# 二级振动均值约 9.1 mm/s，超 ISO 10816 C 区下限；② 4# 排气/绕组温升偏高；③ 4#/5# B 相电流全程为 0（数据质量）
- **方案闭环**：`PLAN-20260910-001` 正常执行+复盘；`PLAN-20260911-002` 回执超时→状态未知→待处置
- **数据**：2026-03-12 ~ 2026-09-12 分钟级真实归档，聚合为日级/小时级/实时/预测；以数据中点分界做前后半程对比
- **安全演示开关**（数据与策略页）：「模拟数据异常」开启后禁止生成可下发方案；「模拟高风险」开启后阻断已批准方案下发

## 指标口径说明

页面区分「赛题目标值 / 真实计算值 / 基线期」。真实数据为连续运行归档，**不含 AI 调度干预前后对照**，因此能效类指标展示的是真实数据前后半程对比，不等同于 AI 节能收益。每个指标可追溯至数据时段或方案。

## 演示内容清单

- 运行数据、时序聚合、负荷预测均来自真实数据包
- 调度推理（贪心寻优 + 约束校核 + 可解释文本）、健康诊断、压力/振动约束校核为演示逻辑
- 控制 API 与回执（成功/失败/超时）、Agent 意图识别与回答为演示逻辑
- 用户操作（审批/工单/策略等）通过 Zustand persist 保存于浏览器 localStorage，刷新后保留

## 数据依赖说明

不使用任何真实 API Key 或付费服务；SCADA/PLC/EAM 在界面中为数据源占位，站点运行数据来自随包提供的真实数据文件。
