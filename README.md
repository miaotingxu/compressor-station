# 空压站多机协同智能调度 Agent

面向制造企业空压站运维人员、能源管理人员、设备工程师和管理者的工业 Web 智能应用。
具备「感知 → 推理 → 决策 → 人工确认 → 执行 → 验证 → 学习」完整闭环的多机协同调度 Agent（演示环境）。

- 工厂 / 站点：海川精工 · 1 号空压站
- 默认免登录，顶部可切换四种角色（值班员 / 能源负责人 / 设备工程师 / 系统管理员）体验权限差异
- 所有运行数据、控制指令、回执、收益均为**本地模拟数据**，页面各处均有「演示环境」标识

## 技术栈

React 18 + TypeScript + Vite 5 + Ant Design 5 + ECharts 5 + Zustand（含 localStorage 持久化）+ React Router 6

## 启动方式

```bash
# 安装依赖
npm install

# 开发模式（http://localhost:5173）
npm run dev

# 生产构建 + 生产模式预览（推荐，内存占用最低）
npm run build
npm run preview
```

## 核心业务故事线（验收演示路径）

1. **发现低效**：工作台/运行管理可见 AC-03 长期低加载率（约 32%，"大马拉小车"）告警。
2. **生成方案**：智能调度页点「一键生成调度方案」，约 4 秒完成（模拟 ≤60 秒目标），产出三套候选方案与解释依据。
3. **人工审批**：比较三套方案的节能收益/压力风险/设备风险，可编辑参数后以「值班员」批准（或驳回并填写原因）。
4. **模拟下发**：执行中心确认影响范围后下发，逐设备返回回执；AC-04 网关约 30% 概率超时 → 方案标记「状态未知」→ 重新下发或人工处置。
5. **效果复盘**：执行完成展示实际节电、压力合格率、加载率偏离与收益可信度说明。
6. **预测运维**：设备健康页查看 AC-02 轴承诊断（提前 36h）与 AC-01 喘振风险（提前 45s），一键建单。
7. **工单闭环**：以「设备工程师」指派 → 开工 → 提交复测数据 → 验收关闭（无复测数据时禁止关闭）。
8. **策略学习**：以「管理员」查看策略候选版本（源自驳回原因与执行效果）、历史回放结果，发布 V1.3.0 或回滚。
9. **Agent 问答**：询问"为什么建议停掉 AC-03？""当前有哪些喘振风险？""帮我生成调度方案"等，回答含结论/依据/风险/下一步；控制意图只会创建待审批方案。

## 预置演示场景与实体

- **设备**：AC-01~AC-05 空压机（离心/螺杆，含性能曲线）、DR-01/02 干燥机、AT-01/02 储气罐
- **三类异常**：① AC-03 低加载率"大马拉小车"；② AC-02 轴承温度/振动异常（预测性维护）；③ AC-01 喘振裕度收窄（高风险安全拦截，可在数据与策略页开启模拟）
- **两个方案闭环**：`PLAN-20260919-001` 正常执行+复盘（节电 1286 kWh）；`PLAN-20260920-002` 回执超时→状态未知→待处置
- **数据**：30 天小时级历史时序（前 15 天人工基线 / 后 15 天 AI 调度期）、未来 4h 负荷预测、告警、工单、策略版本、月度报告
- **安全演示开关**（数据与策略页）：「模拟数据异常」开启后禁止生成可下发方案；「模拟高风险喘振」开启后阻断已批准方案下发

## 指标口径说明

页面明确区分「赛题目标值 / 当前模拟值 / 历史基线 / 模拟回放结果」，每个指标可追溯至数据时段、调度方案或工单（见「能效与收益」页指标达成表）。所有当前值为模拟数据推演，不代表真实生产结果。

## 演示内容清单（均为模拟）

- 设备实时数据（12 秒模拟刷新）、30 天历史时序、负荷预测曲线
- AI 调度推理（贪心寻优 + 约束校核 + 可解释文本生成）、负荷预测、健康诊断、喘振边界模型
- 控制 API 与回执（成功/失败/超时）、策略回放、Agent 意图识别与回答
- 用户操作（审批/工单/策略等）通过 Zustand persist 保存于浏览器 localStorage，刷新后保留

## 无真实外部依赖

不使用任何真实 API Key 或付费服务；SCADA/PLC/EAM/MES 均为本地模拟数据源。
